## 二、对话 Tab（交互层，落地 P0）

### 2.1 消息操作行（新增，P0）
```
┌──────────────────────────────┐
│ 消息内容                      │
│ ──────────────────────────── │
│ 📋复制  🔄重生成  🗑删除  ⋯更多 │  ← 生成完成后显示；生成中隐藏
└──────────────────────────────┘
```
- 挂 ChatMessage.kt 同级组件；删除带确认；生成中禁止删除（对齐 RikkaHub ChatVM 行为）
- 「更多」BottomSheet：分享/导出

### 2.2 思维链步骤卡（增强，P0）
- `ReasoningBlock → 其调用的 ToolCard` 按 toolCallId 组合为链式卡
- **同一工具调用只保留最新状态卡**（running→success 原位替换，已实施于 ChatViewModel `tool_dispatch` 分支）
- Pending 审批强制展开；loading 显示 DotLoading

### 2.3 推理卡三态折叠（增强，P0）
- Collapsed（渐隐预览）/ Expanded（全文）/ 生成中 shimmer + 时长
- 完成后按设置自动收起（对齐 RikkaHub `autoCloseThinking`）

### 2.4 审批四按钮（对齐，P0）
- 协议已支持 `approve(id, allow, session, persist, scope)`
- UI：✅允许 / ♾️始终允许 / 💬本聊天允许 / ❌拒绝（+理由）
- 去掉 RikkaHub 特有工具安全提示（Reasonix 无 schedule_job/MCP 工具集）

### 2.5 token 累计条（增强，P0）
- 输入框下会话级统计条：`↑输入 / 缓存 / ↓输出`，可复制
- **同一回合多次 usage 只保留最新一张卡**（服务端推累计快照，已实施：快照覆盖 + 原位替换）
- 受 `showTokens` 开关控制（已接线）

### 2.6 已实施的收敛（本轮 98c234d）
| 项 | 行为 |
|---|---|
| usage 卡 | 同回合只留最新一张；累计改快照覆盖（防虚高） |
| tool 卡 | 同 id 原位替换，保留最新状态 |
| showTokens | 关闭时不生成统计卡，累计仍更新 |
| 侧边栏入口 | 移到 Footer 输入框同一行（bf0fe63） |
| 左上角 | 品牌块改为用户名首字母头像（bf0fe63） |

## 三、Run Tab（方向 B 骨架）

- **发起**：Footer ⚡ 或 DAB → ModalBottomSheet 参数面板（任务描述 + 模型 chips + 高级参数折叠 + 附件）
- **进行中**：步骤卡片列表（⏳/✅/❌/⏸ 可展开日志）+ Token 仪表盘实时刷新（↓input/↑output/缓存率/耗时）
- **完成**：结果 Tab 激活 + 通知；Markdown/代码渲染，一键复制分享，可继续追问
- **侧边栏增强**：会话列表项运行状态指示器（🔴 进行中高亮）

> 依赖服务端 `run` 模式协议；前端以 `StateFlow<List<RunStep>>` 驱动。

## 四、设置系统（可移植子集照搬）

### 4.1 分组结构（照搬 RikkaHub，裁剪特有项）

```
设置
├─ 外观与聊天 UI（SettingPreferencesUIPage 对应项）
│   ├─ 动态色（Switch）
│   ├─ 主题（预设 7 套 + 自定义主题增删导入导出 + AMOLED）
│   ├─ 聊天字体（默认/衬线/等宽/JetBrains Mono + 自定义导入）
│   ├─ 字号（Slider，fontSizeRatio）
│   ├─ 气泡/头像开关（showUserAvatar / showAssistantBubble / bubbleOpacity）
│   ├─ 显示 token 统计（showTokenUsage → 已接线）
│   ├─ 显示思考内容 / 完成后自动收起（showThinkingContent / autoCloseThinking）
│   ├─ LaTeX / 代码块换行 / 行号
│   └─ 自动滚动 / sendOnEnter / 消息跳转
├─ 对话与模型
│   ├─ 默认对话模型（chatModelId）＋ 快速模型（fastModelId）
│   ├─ 标题模型 / 翻译模型（可选，服务端支持则显示）
│   ├─ 自动压缩（autoCompressEnabled / Threshold / TokenLimit / Mode）
│   ├─ 工具输出截断（toolOutputMaxChars）
│   ├─ 快捷消息（quickMessages）
│   └─ per-assistant temperature（非全局字段，RikkaHub 亦如此）
├─ 通知
│   ├─ 更新提醒（showUpdates）
│   ├─ 生成完成通知 / 实时进度通知
└─ 关于
    ├─ 版本 / 文档 / 日志
    └─ 分享
```

### 4.2 存储与安全（原样保留）
- **Preferences DataStore**（`preferencesDataStore(name="settings")`），Key 定义 + 迁移 V1/V2/V3
- **凭证加密**：AndroidKeyStore AES-256-GCM（`ProviderCredentialCipher` 模式），Base64(IV+Ciphertext)，密钥不进备份，解密失败回退明文平滑升级
- 少数偏好可走 SharedPreferences（如新建会话行为）

### 4.3 整组剔除（RikkaHub 特有）
80+ 本地设备工具（无障碍/Termux/SSH/NFC/指纹/短信）、TTS/ASR、OCR（ML Kit）、Quota 额度、搜索服务、MCP、Web 服务器、Telegram Bot、工作流/定时任务、内置浏览器、WebDAV/S3 备份、图像生成模型、多助手技能、Doctor、开发者模式/捐赠。
